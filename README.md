# Deutsch A2 Trainer — practical German for daily life

Installable iPhone web app: https://surya-sudhakar.github.io/deutsch-a2-trainer/

## Current release
261 bilingual example phrases across 43 topics, audio playback using browser text-to-speech, flashcards, multiple-choice quizzes, learned-phrase tracking and basic offline caching. Progress is saved locally on each device.

**Important:** This is a growing learning app, **not yet a complete A2 course** or an official Goethe/telc examination preparation product. No speaking recognition, placement assessment, cloud sync or adaptive spaced repetition is implemented yet.

## Suggested study progression
- Weeks 1–2: introductions, routine, time, shopping, transport and directions. Say answers aloud without reading.
- Weeks 3–4: colleagues, work, home, doctors, insurance, appointments and official offices. Practise role-play responses.
- Weeks 5–6: Perfekt, modal verbs, accusative/dative, subordinate clauses with *weil*, *dass*, *wenn*, *obwohl*.
- Weeks 7–8: extended responses, describing problems, giving opinions, linking reasons and preparing for B1 discussions.

**Daily practice (20–30 minutes):** 5 min review, 10 min new phrases, 10 min aloud responses, 5 min free speech about your day. Revisit old topics weekly.

## B1 readiness
You should be able to describe recent events, handle routine unexpected situations, explain plans and reasons, maintain an unscripted everyday conversation, and understand clear standard speech on familiar topics. Use a recognized placement test and representative Goethe/telc model exams to evaluate readiness.
